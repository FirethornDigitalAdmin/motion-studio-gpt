# Louis clean rig

A separate flat vector character rebuild. Add **Louis clean rig** from Motion Studio's Character library; the original Louis rig remains available. **Louis model sheet** is the front / three-quarter / profile drawing reference.

The library contains 57 independently registered SVG parts: three head views, torso/neck/pelvis, arm and leg parts, eleven hand drawings per anatomical side, eyes/pupil/brow, and fifteen distinct mouth drawings. There are no embedded bitmap patches or gradients in the rig parts. The generated model sheet is a design reference; the animated rig uses editable vector artwork.

Rig version 3 uses artwork-specific eye, brow and mouth positions. **Head view** records native drawing-view keys. Head turns swap drawings during authored blinks; the body remains in its existing orientation. This is not a 360-degree body rig.

For the supplied default arm artwork, the editor draws a continuous rounded contour through the solved shoulder, elbow and wrist, with a sleeve that merges into the torso. Limb lengths and bend controls remain editable, and contacts use the normal IK solver. Replacement arm drawings use the ordinary asset-rendering path. Compact hand drawings share a wrist registration and follow forearm rotation.

The native **Louis - Clean Rig Acting Test.motion** project contains a five-second acting study, with an existing Louis Voice 1 recording, native mouth keys, three blink gestures, a restrained wrist gesture, head view changes and a reaction close-up. It also saves **Louis clean rig** as a project-library template. The hidden earlier actor is retained for comparison.

Review the film at full size, especially the raised arm, beard/neck junction and speaking close-up. Reach/contact diagnostics and automated tests check mechanical consistency; they do not certify broadcast animation quality.
